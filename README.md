### 🚀 About Me

I am a software engineer with a passion for mobile and web app development as well as knwoledge in machine learning and system architecture design. My projects are built from the ground up which means that planning, designing, testing and prototyping all done through the Software Development Lifecycle. I am a dedicated and self motivated individual with a passion for learning new technologies while harnessing innovative technologies in this technological era. My finest work to date was the GreenSpace application I developed where soil classification and fertility prediction and labelling was done through an image recognition system trained using Python and its relevant frameworks. The project also featured dedicated communitty engagement and events planning to help fascilitate environmental discussions and protection. This project was awarded most innovative project by a male student at Telone Center For Learning, my alma mater. Other notable I am currently  working on enhancing my tech knowedge in all fieds of software engineering and development by learning dev ops and machine learning and artificial intelligence

🔭 &nbsp;I'm currently working on **Welfare Tracker, a geofence and realtime location tracking mobile app for family safety, SageOS- a custom made operating system made from scratch using C and Assembly, HighSpecHR- A tech inspired and high performance web app for recruitement, selection, psychometrci assessment and easy hiring decision, GlobalTravel- a travel web app insfused with location search and realiable payment gateway and DigitalTwin- a 3D model of a farm where weather changes, crop monitoring is made possible through uses of OpenWeather API and sensor data**
